How to play

  1. Enable Allow bots to join to add opponents in this local game.
  2. Choose your rules and select Start Game.
  3. Roll the dice, buy properties, and collect rent. Complete a country set to build houses and hotels.
  4. Stay solvent and be the last player standing.

This project runs locally. Online multiplayer is not connected.
