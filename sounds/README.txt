Put your sound files in this folder using these exact filenames:

1. dice-roll.mp3       - dice rolling/shaking
2. token-move.mp3      - fast player hover/fly movement
3. token-land.mp3      - player lands on a tile
4. buy-land.mp3        - property purchased
5. rent-paid.mp3       - rent paid to another player
6. money-loss.mp3      - tax / generic money loss
7. pass-start.mp3      - passing or being sent to START and receiving cash
8. build-house.mp3     - build one house
9. build-hotel.mp3     - upgrade to a hotel
10. sell-building.mp3  - sell house/hotel
11. sell-land.mp3      - sell land back to the bank
12. mortgage.mp3       - mortgage a property
13. unmortgage.mp3     - unmortgage a property
14. card.mp3           - Treasure/Surprise card appears
15. death-valley.mp3   - Death Valley curse / penalty
16. jail.mp3           - sent to prison
17. win.mp3            - local player wins
18. game-over.mp3      - local player loses

The game already calls these sound names. Missing files are ignored safely,
so you can add them one by one.
