## 📤 دفع الأسعار للحافة الخارجية (تفضي المساحة فالوسط للاعبيين)

تعديل فـ `css/style.css` باش الأسعار تتحرك **بعيد عن مركز الطاولة** — لكل ضلع كيتبع حافته الخارجية:

- الشريط **العلوي**: السعر طالع **زيادة لفوق** (`top: 7px`).
- الشريط **السفلي**: السعر نازل **زيادة لتحت** (`bottom: 7px`).
- العمود **اليمين**: السعر مزاح **زيادة لليمين** (`right: 1px`).
- العمود **اليسار**: السعر مزاح **زيادة لليسار** (`left: 1px`).

وكيتما الأيقونات والأسماء فالخانات الخاصة (`row-special`) ليتفرقو فطبقات:
- السعر فالحد الخارجي، ومن بعد الأيقونة، ومن بعد الاسم — بلا تداخل.
- وسط كل خانة ولى خالي باش اللاعب يهبط/يلعب فوق الأرض (التوكن).

قياسات موثّقة (بالبكسل من حافة الخانة):
- TOP: السعر `T=3` / BOTTOM: `B=3` / RIGHT: `R=2` / LEFT: `L=2` — كلهم على الحافة الخارجية.
