# Third-party assets added for the settings panel

## Font Awesome Free 5.15.4

Copyright Fonticons, Inc. https://fontawesome.com/

The users, key, robot, map-marker/map, coins, gavel, hand-holding-dollar, shuffle, and check SVG paths embedded in `index.html` come from Font Awesome Free. Icons are licensed under CC BY 4.0. See `Font-Awesome.txt` for the distribution's license and links to the full terms. They are displayed in monochrome at the reference control sizes.

The island/palm, prison-rent chart, buildings, starting-cash flag, crown, palette, exit arrow, and chevron are custom SVG drawings for this interface; no Font Awesome Pro assets are included.

## Roboto

Roboto Latin normal weights 400, 500, and 700 are distributed locally in `assets/fonts/`, sourced from `@fontsource/roboto` 5.2.6. Copyright Google Inc. Licensed under the SIL Open Font License 1.1; see `Roboto-OFL.txt`.

Other existing assets in the repository have not been replaced by this update.

## Sidebar icons (v23)

The copy, paper-plane/send, and search-plus SVG paths are also from Font Awesome Free 5.15.4 (CC BY 4.0). The Discord mark is reused from the original project. Speaker, muted-speaker, help, info, expand/restore, close, and message-bubble icons are local SVG drawings. No externally hosted icons or fonts are required.
