RICHORA — VERCEL READY

This folder is ready for a static Vercel deployment.

Recommended:
1. Extract this ZIP.
2. Open a terminal inside the extracted folder.
3. Run: npx vercel --prod
4. If prompted, link it to your existing Vercel project.

The project root already contains index.html and vercel.json.
Room links now use the deployed domain automatically.

Note: This package preserves the current local game logic. A shared room URL does not by itself add a real multiplayer backend/state sync.
